# 평점 (별점·리뷰·인상 깊은 문장·오늘의 문장)

독서 앱에서 읽은 책에 별점을 남기고, 선택으로 리뷰와 인상 깊은 문장을 적는 기능입니다. 남긴 문장은 홈의 "오늘의 문장"으로 다시 보입니다. 구현 근거는 스펙 이슈 #30.

## 무엇
- 평점은 **책 상세의 "평점 추가하기 / 평점 고치기" 버튼**으로만 들어갑니다(하단 탭에 "평점"은 없음). 읽은 책(`done`)에만 남길 수 있습니다.
- 입력: 별점(0.5~5, 0.5 단위, **필수**), 리뷰(여러 줄, 최대 1000자, 선택), 인상 깊은 문장(여러 개, 문장당 500자, 선택).
- 저장하면 그 책 상세로 돌아가고 토스트("rated")가 뜹니다.
- 홈: **오늘의 문장** 버튼(문장이 있을 때만)과 **미평점 책 모달**(로그인한 멤버, 하루 한 번).
- 홈 인사말은 로그인한 사람에게는 없고, 게스트는 "독서 모임 기록" 제목이 보입니다. 위쪽 "평점 안 남긴 책" 카드와 "최근 한 줄 평"은 없어졌습니다.

## 어떻게 동작하나
- **데이터**: `book_ratings`(책×멤버당 한 줄, `review` 열), `book_quotes`(책, 멤버, 순서 `ord`, 문장; `unique(book_id, member_id, ord)`).
- **저장**(`app/(main)/rate/actions.ts`): 첫 줄에서 `getCurrentMember()`로 로그인 확인 → zod 검증(`lib/validation/rating.ts`: 리뷰 CRLF→LF·앞뒤 공백 자르기·빈 값은 null, 문장 빈 칸 건너뛰기, 한 번에 50개 상한) → 평점 upsert → 문장을 `ord` 기준 upsert하고 남는 `ord`는 삭제. 평점과 문장은 한 트랜잭션이 아닙니다.
- **오늘의 문장**(`lib/daily-quote.ts`, `daily-quote-action.ts`, `components/daily-quote.tsx`): 서울 날짜를 해시해 정렬된 문장 id 중 하나를 고르므로 하루 동안 모두에게 같습니다. "다른 문장 보기"는 안 본 것 중 무작위, 다 보면 다시 시작(직전 문장은 피함). 문장은 서버 액션으로 하나씩 가져옵니다.
- **미평점 책 모달**(`components/unrated-books-modal.tsx`, `unratedBooks` in `lib/stats.ts`): 내가 안 남긴 읽은 책을 모임 날짜 늦은 순으로. 닫으면 `localStorage`의 `book:unrated-modal-day:<멤버id>`에 서울 날짜를 저장해 그날은 다시 안 뜹니다.
- **공용 UI**(두 앱 모두): 클릭 요소 포인터·비활성 `not-allowed` 커서는 `packages/ui/src/theme.css`, 토스트는 타이머 없이 ✕로만 닫고 쌓입니다(`packages/ui/src/toast.tsx`, workout은 `use-overlays.tsx`).
- **백업**: `book_quotes`를 `backup-tables.ts`에 등록했고 옛 구조 백업은 복원 때 변환합니다(`docs/features/backup.md`).

## 특이사항
- **마이그레이션 2개가 열을 지웁니다**(`one_liner`→`review` 복사 후 삭제, `quote`→`book_quotes` 복사 후 삭제). 운영 적용 전에 새 백업을 받아 둡니다. 되돌리려면 백업에서 복원해야 합니다.
- **게스트**: 리뷰·문장·오늘의 문장은 읽을 수 있고 쓴 사람 이름은 `getClubData()`에서 가려집니다. 저장 액션은 로그인 확인으로 막힙니다(`guest-mode.md`).
- **미평점 모달의 "오늘"은 기기·멤버별**입니다. 기기를 바꾸면 다시 뜹니다. DB에는 저장하지 않습니다.
- 평점 자체를 지우는 기능은 없습니다. 리뷰와 문장을 모두 비우고 저장하는 것만 됩니다.
- 토스트는 개수 상한이 없어, 닫지 않으면 계속 쌓입니다.
