# DONE 줄에 등급과 함께 누가 했는지를 남긴다

`DONE.md` 줄은 `- [x] YYYY-MM-DD (P등급·누가) 내용 <!-- id:... -->`로 쓴다. 누가는 TODO 줄의 `(직접)`·`(Claude)`·`(함께)`다. 되돌릴 때 원래 TODO 줄(등급 섹션, 누가)을 그대로 복원하려면 DONE 줄에 그 정보가 남아 있어야 해서다(스펙 #17).

## Consequences

- 이 규칙 이전의 옛 줄(2026-11-15까지)은 `(P등급)`뿐이라 누가가 없다. 되돌릴 때 `(함께)`로 본다. 옛 줄을 일괄 고치지는 않았다.
- TODO 줄에 누가가 없으면 DONE에는 `(P등급)`만 붙고, 되돌리면 `(함께)`가 된다.
