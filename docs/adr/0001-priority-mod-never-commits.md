# 우선순위 mod는 파일만 고치고 커밋·푸시하지 않는다

우선순위 mod(`tools/priority-mod`)는 체크·되돌리기로 `docs/TODO.md`와 `docs/DONE.md`만 고친다. 커밋과 푸시는 하지 않고, 대신 미커밋 변경이 있다는 표시만 띄운다(스펙 #17). 커밋은 사용자가 내용을 확인한 뒤 따로 하는 것이 이 레포의 규칙이고(`CLAUDE.md`), mod가 몰래 커밋하면 그 확인 단계가 사라지기 때문이다.

## Considered Options

- 체크할 때마다 자동 커밋: 되돌리기는 편하지만 확인 없는 커밋이 쌓이고, 잘못 누른 체크가 히스토리에 남는다. 채택하지 않았다.
- 파일만 고침(채택): 잘못 눌러도 `git checkout docs/`로 되돌릴 수 있다. 대신 커밋을 잊을 수 있어서 미커밋 표시를 둔다.
